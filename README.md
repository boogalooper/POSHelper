# POS helper

POS helper позволяет отправлять команды в Photoshop из ярлыка, командной строки или программы для горячих клавиш. Через один VBS-файл можно запускать установленные скрипты по их ID, открывать документы и загружать наборы операций.

## Состав

- `POS helper.jsx` — принимает и выполняет команду в Photoshop.
- `PosHelper.vbs` — передаёт команду из Windows в Photoshop.

## Установка

1. Скопируйте `POS helper.jsx` в папку `Presets\Scripts` установленного Photoshop. 
2. Перезапустите Photoshop, чтобы он зарегистрировал скрипт.
3. Поместите `PosHelper.vbs` в удобную папку. В примерах ниже используется `D:\Scripts\PosHelper.vbs` — замените этот путь своим.

Для работы нужны Windows, Photoshop с поддержкой JSX и COM-автоматизации и доступный Windows Script Host. Python и дополнительные модули не нужны.

## Запуск

VBS можно запускать напрямую, без указания `wscript.exe`:

```bat
"D:\Scripts\PosHelper.vbs" "цель" "параметры"
```

Также можно явно указать обработчик:

```bat
wscript.exe "D:\Scripts\PosHelper.vbs" "цель" "параметры"
```

Первый аргумент — обязательный: ID установленного скрипта или путь к файлу. Второй аргумент — необязательная строка параметров для запуска скрипта по ID.

Эту команду можно указать в поле «Объект» ярлыка Windows или вызвать из программы для горячих клавиш. Сам POS helper сочетания клавиш не назначает.

### Запуск скрипта по ID

```bat
"D:\Scripts\PosHelper.vbs" "7a4144e4-943e-4b5f-8d40-06dfc90b682b"
```

Целевой скрипт должен быть установлен и зарегистрирован в Photoshop. Его ID указан в теге `<eventid>` в начале JSX-файла. POS helper распознаёт ID в формате UUID версии 4, как в примере выше.

### Передача дополнительных параметров скрипту

```bat
"D:\Scripts\PosHelper.vbs" "03c3cc32-600d-4e47-ad5c-2b11c0f5f176" "--dialog"
```

POS helper передаёт строку параметров целевому скрипту через поле `args` в `app.playbackParameters`. Вся строка должна быть одним аргументом, заключённым в кавычки.

Значение параметров определяет сам целевой скрипт. Например, `--dialog` откроет настройки только в том случае, если скрипт поддерживает этот параметр.

### Запуск с путём к файлу

Если передать путь к файлу, POS helper открывает документ либо загружает набор операций ATN.

Открытие документа:

```bat
"D:\Scripts\PosHelper.vbs" "D:\Photos\Фото.psd"
```

Загрузка набора операций:

```bat
"D:\Scripts\PosHelper.vbs" "D:\Actions\Ретушь.atn"
```

**Перед загрузкой ATN скрипт удаляет все текущие наборы операций из панели «Операции» (Actions).** Поэтому заранее сохраните собственные операции в файлы. Файлы ATN на диске не удаляются.

После этого загружается указанный набор. Операции из него автоматически не запускаются. Если файл не удастся загрузить, удалённые наборы автоматически не восстанавливаются.

В этой версии используйте расширение `.atn` строчными буквами: проверка в коде чувствительна к регистру.

## Если ничего не происходит

- Проверьте путь к VBS и наличие первого аргумента. Запуск VBS двойным щелчком без аргументов ничего не делает.
- Убедитесь, что `POS helper.jsx` установлен, и перезапустите Photoshop после установки.
- При запуске по ID проверьте `<eventid>` целевого скрипта и его установку.
- При загрузке файла проверьте полный путь и доступ к нему.
- Если параметры не действуют, проверьте, поддерживает ли их целевой скрипт.
- Убедитесь, что Windows Script Host не отключён в Windows.

VBS подавляет сообщения об ошибках, поэтому неудачный вызов может завершиться без уведомления. Обычный запуск POS helper из меню Photoshop без переданной команды также ничего не делает.
